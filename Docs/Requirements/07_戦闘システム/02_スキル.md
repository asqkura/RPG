# スキル

親: [07_戦闘システム.md](../07_戦闘システム.md)

## スキル

- スキルはSPを消費して使用する。
- 攻撃、回復、補助、弱体、状態異常などの効果を持てる。
- キャラクターごとの基本スキルはレベルアップで習得する。
- 装備由来のスキルは、装備中のみ使用できる。
- スキルは戦闘中のみ使用できる。
- キャンプや探索中にスキルは使用しない。

### スキル基本方針

- スキルには基本分類を持つ。
- スキルは `effects` として複数効果を持てる。
- 効果はデータに定義された順番で処理する。
- 吸血、ダメージ + 毒、攻撃 + 防御低下、回復 + 防御上昇などを表現できる。

### スキル分類

- `physicalAttack`
  - 物理攻撃。

- `magicAttack`
  - 魔法攻撃。

- `heal`
  - 回復。

- `buff`
  - 強化。

- `debuff`
  - 弱体。

- `status`
  - 状態異常。

### 効果タイプ

- `damage`
  - ダメージを与える。

- `heal`
  - HPを回復する。

- `buff`
  - 攻撃上昇、防御上昇など。

- `debuff`
  - 攻撃低下、防御低下など。

- `status`
  - 毒、スタンなど。

- `drain`
  - 与えたダメージの割合で自分を回復する。

- `cleanse`
  - 状態異常・弱体などを解除する。

### 効果処理順

- `effects` に定義された順番で処理する。
- ダメージ後に吸血、ダメージ後に毒付与などを表現できる。
- デバフを先に入れてからダメージ、というスキルも作れる。
- 処理順はスキルデータ側で明示する。

例:

```text
吸血:
effects:
  1. damage
  2. drain
```

```text
防御崩し:
effects:
  1. debuff 防御低下
  2. damage
```

```text
毒斬り:
effects:
  1. damage
  2. status 毒
```

### 対象指定

- スキル全体に `targetType` を持つ。
- 各効果は基本的に `target: default` を使う。
- 必要な効果だけ `target` を上書きできる。

`targetType` 例:

- `enemySingle`
- `enemyAll`
- `allySingle`
- `allyAll`
- `self`

`effect target` 例:

- `default`
  - スキル全体の対象を使う。

- `self`
  - 使用者自身。

- `target`
  - 選択対象。

- `allEnemies`
  - 敵全体。

- `allAllies`
  - 味方全体。

### drain

- `drain` 効果は単体攻撃スキルにのみ付与できる。
- 敵全体攻撃 + `drain` は初期要件では扱わない。
- 回復量は、対象1体に実際に与えた最終ダメージを基準にする。

```text
回復量 = 対象1体への最終ダメージ × drainRate
```

実際に与えたダメージには以下を含む。

- 防御軽減後
- 属性倍率後
- 隊列補正後
- 乱数後
- 会心後

### cleanse

初期の標準 `cleanse` は以下を解除する。

- 毒
- スタン
- 攻撃低下
- 防御低下

解除しないもの:

- 攻撃上昇
- 防御上昇

標準の `cleanseType` は `negativeOnly` とする。
将来的に敵のバフ解除を作る場合は、`positiveOnly` や `all` を検討する。

### SkillData

- `skillId`
  - 一意ID。

- `name`
  - 表示名。

- `description`
  - 説明文。

- `iconSprite`
  - スキルアイコンSprite参照。
  - スキル一覧や戦闘コマンドで表示する。

- `category`
  - `physicalAttack`
  - `magicAttack`
  - `heal`
  - `buff`
  - `debuff`
  - `status`

- `spCost`
  - 消費SP。

- `targetType`
  - `enemySingle`
  - `enemyAll`
  - `allySingle`
  - `allyAll`
  - `self`

- `usableBy`
  - `character`
  - `equipment`
  - `enemy`

- `effects`
  - 効果一覧。
  - 定義された順番で処理する。

- `sortOrder`
  - スキル一覧での表示順。

- `animationId`
  - 使用時の演出ID。

- `soundEffectId`
  - 使用時のSE ID。

### SkillEffect

- `effectType`
  - `damage`
  - `heal`
  - `buff`
  - `debuff`
  - `status`
  - `drain`
  - `cleanse`

- `target`
  - `default`
  - `self`
  - `target`
  - `allEnemies`
  - `allAllies`

- `referenceStat`
  - `attack`
  - `magic`
  - `none`

- `multiplier`
  - ダメージ/回復倍率。

- `fixedValue`
  - 固定値。

- `element`
  - 属性。

- `canCritical`
  - 会心可否。

- `statusType`
  - 毒、スタンなど。

- `buffType`
  - 攻撃上昇、防御上昇など。

- `durationActions`
  - 継続行動回数。

- `successRate`
  - 基本成功率。

- `healType`
  - 固定値
  - ステータス参照
  - 割合
  - 割合 + 固定値

- `healRate`
  - 回復割合。

- `drainRate`
  - 与ダメージに対する回復割合。

- `cleanseType`
  - `negativeOnly`
  - 将来的に `positiveOnly` / `all` も検討可。
