# 状態異常と状態変化

親: [07_戦闘システム.md](../07_戦闘システム.md)

## 状態異常・状態変化

初期状態異常・状態変化は以下に絞る。

- 毒
- スタン
- 攻撃低下
- 防御低下
- 攻撃上昇
- 防御上昇

状態異常・状態変化は戦闘中に発生し、戦闘終了時に基本解除される。
状態異常回復アイテムやスキルで解除できる。
装備やアクセサリで耐性を持たせられる。

### 継続管理

- 状態異常やバフ/デバフは、残り行動回数で管理する。
- 付与するスキルごとに `durationActions` を持つ。
- 対象が行動を終えるたびに `durationActions` を1減らす。
- `durationActions` が0になると解除される。
- スタンなどで行動不能になった場合も、行動をスキップした時点で1減らす。
- 戦闘終了時には基本解除される。

この方式は通常ターン制でもCTBでも使える。

HP/SPの消耗はクエスト中に引き継ぐが、状態異常・状態変化は戦闘をまたいで引き継がない。

### 毒

- 対象の行動終了時に毒ダメージを受ける。
- 毒ダメージは対象の最大HP割合で計算する。
- 毒の割合は、付与するスキルごとに設定する。
- 例: 最大HPの5%、8%、10%など。
- 毒ダメージには乱数を入れない。
- 毒ダメージでHPが0になった場合、戦闘不能になる。
- 敵も味方も同じルールとする。

### スタン

- スタン中の対象は、次の行動タイミングで行動できない。
- 行動をスキップした時点でスタンを解除する。
- 基本は `durationActions = 1`。
- 複数回行動不能のスタンは初期要件では扱わない。
- ボスや重要敵にはスタン耐性を持たせられる。

### 攻撃低下

- 対象の攻撃を20%下げる。
- 物理通常攻撃、物理スキルのダメージに影響する。
- 魔力には影響しない。

```text
攻撃低下中の攻撃 = 攻撃 × 0.8
```

### 防御低下

- 対象の防御を20%下げる。
- 物理・魔法どちらの被ダメージにも影響する。
- 防御軽減式に入る防御値を下げる。

```text
防御低下中の防御 = 防御 × 0.8
```

### 攻撃上昇

- 対象の攻撃を20%上げる。
- 物理通常攻撃、物理スキルのダメージに影響する。
- 魔力には影響しない。

```text
攻撃上昇中の攻撃 = 攻撃 × 1.2
```

### 防御上昇

- 対象の防御を20%上げる。
- 物理・魔法どちらの被ダメージにも影響する。

```text
防御上昇中の防御 = 防御 × 1.2
```

### 重ねがけ

- 同じ状態変化は重ねがけ不可。
- すでに同じ効果が付いている場合、効果量は増えない。
- 残り行動回数が長い方を採用する。
- 短い効果で長い効果を上書きしない。

例:

```text
攻撃上昇 残り3行動
→ 攻撃上昇 残り2行動を再付与
→ 残り3行動のまま
```

```text
防御低下 残り1行動
→ 防御低下 残り3行動を再付与
→ 残り3行動に更新
```

### 相殺

反対効果が付与された場合は、相殺して両方消える。

- 攻撃上昇中に攻撃低下を受けた場合
  - 攻撃上昇を解除する。
  - 攻撃低下は付与しない。

- 攻撃低下中に攻撃上昇を受けた場合
  - 攻撃低下を解除する。
  - 攻撃上昇は付与しない。

- 防御上昇と防御低下も同様。

### 付与成功率

状態異常や敵へのデバフは、スキル基本成功率と対象耐性で判定する。

```text
最終成功率 = clamp(スキル基本成功率 - 対象耐性, 0%, 100%)
```

- 0%なら絶対に付与されない。
- 100%なら必ず付与される。
- ボスや重要敵に完全耐性を持たせられる。
- イベントや特殊スキルで確定付与も可能。

### バフ/デバフ成功判定

- 味方への攻撃上昇・防御上昇
  - 必ず成功する。

- 敵への攻撃低下・防御低下
  - スキル基本成功率と対象耐性で判定する。

- 毒・スタン
  - スキル基本成功率と対象耐性で判定する。

- 敵が敵自身に使うバフ
  - 必ず成功する。

- 敵が味方側へ使うデバフ/状態異常
  - スキル基本成功率と対象耐性で判定する。

### 耐性種別

- 状態異常耐性
  - 毒
  - スタン

- 弱体耐性
  - 攻撃低下
  - 防御低下

例:

```text
毒付与スキル 基本成功率70%
対象の状態異常耐性20%
→ 最終成功率50%
```

```text
防御低下スキル 基本成功率80%
対象の弱体耐性30%
→ 最終成功率50%
```
