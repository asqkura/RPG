# 戦闘計算式

親: [07_戦闘システム.md](../07_戦闘システム.md)

## ダメージ計算

### 基本方針

- 防御は割合軽減型にする。
- 物理ダメージも魔法ダメージも、防御ステータスで軽減する。
- 精神・魔法防御のような別ステータスは初期要件では追加しない。
- 表示される攻撃・魔力・防御などは、装備補正込みの最終値とする。
- ダメージ計算では、表示されている最終ステータスを使う。
- 計算結果は最終的に整数へ丸める。

### 防御軽減

```text
軽減後ダメージ = 基礎威力 × 100 / (100 + 防御)
```

防御の効き方の目安:

```text
防御 0   → 100%
防御 50  → 約67%
防御 100 → 50%
防御 200 → 約33%
```

### 通常攻撃

通常攻撃属性は装備中の武器タイプから決定する。

```text
通常攻撃ダメージ =
攻撃
× 100 / (100 + 対象防御)
× 属性倍率
× 隊列補正
× 乱数
```

### スキルデータ

スキルには以下を持たせる。

- 参照ステータス
  - 攻撃
  - 魔力

- 倍率
  - 例: 1.2倍、1.8倍など。

- 属性
  - 斬 / 打 / 突 / 火 / 水 / 雷 / 風 / 光 / 闇

- SP消費

- 対象
  - 敵単体
  - 敵全体
  - 味方単体
  - 味方全体
  - 自分

- 効果
  - ダメージ
  - 回復
  - バフ
  - デバフ
  - 状態異常
  - 複合効果

### 物理スキル

```text
物理スキルダメージ =
攻撃 × スキル倍率
× 100 / (100 + 対象防御)
× 属性倍率
× 隊列補正
× 乱数
```

### 魔法スキル

```text
魔法スキルダメージ =
魔力 × スキル倍率
× 100 / (100 + 対象防御)
× 属性倍率
× 乱数
```

## 回復計算

回復スキルは、スキルごとに回復方式を持つ。
回復量には基本的に乱数を入れない。

### 固定値回復

```text
回復量 = 固定値
```

### ステータス参照回復

```text
回復量 = 固定値 + 参照ステータス × 回復倍率
```

### 割合回復

```text
回復量 = 対象最大HP × 回復割合
```

### 割合 + 固定値回復

```text
回復量 = 対象最大HP × 回復割合 + 固定値
```

### 使い分け

- 手当、応急処置、包帯
  - 割合回復。
  - ステータスなし。

- ヒール、癒しの光
  - 魔力参照回復。

- 薬品系スキル
  - 固定値回復、または割合 + 固定値。

## 会心

- 会心は通常攻撃と物理スキルに発生する。
- 魔法スキル、回復スキル、補助スキルには発生しない。
- 会心発生時、最終ダメージを1.5倍にする。
- 会心率はステータスとして表示する。
- 会心率は最大100%。
- 100%なら通常攻撃・物理スキルが確定会心になる。

## 乱数

ダメージ乱数は±10%とする。

```text
乱数 = 0.9 〜 1.1
```

- ダメージ計算の最後に乗算する。
- 同じ攻撃でも少しダメージが揺れる。
- 回復量には基本的に乱数を入れない。
- 毒などの固定ダメージにも基本的に乱数を入れない。

## 属性倍率

属性倍率は以下とする。

- 通常: `1.0`
- 弱点: `1.3`
- 耐性: `0.7`

弱点を突くと戦闘が楽になるが、属性を突かないと勝てないほどにはしない。

## 隊列補正

- 前衛からの攻撃: `1.0`
- 後衛からの弓・杖攻撃: `1.0`
- 後衛からの剣・短剣・斧・槍攻撃: `0.7`

対象:

- 通常攻撃
- 近接系の物理スキル

補足:

- 魔法スキルや回復スキルは、後衛でも低下しない。
- スキルごとに例外を持たせる余地は残す。
