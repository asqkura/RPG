# 装備

親: [06_装備合成ショップ.md](../06_装備合成ショップ.md)

## 基本方針

- 装備は戦闘攻略の主要要素とする。
- エンディング分岐の主条件にはしない。
- 装備は性能、アクティブスキル、パッシブで個性を出す。
- レアリティは採用しない。
- 装備のランダム性は、その装備らしさを伸ばす方向に限定する。

## 装備スロット

- 武器: 1枠
- 防具: 1枠
- アクセサリ: 2枠

## 装備制限

- 武器はキャラクター、または武器タイプによる装備制限を持つ。
- 防具は基本的に全員装備可能。
- アクセサリは基本的に全員装備可能。
- 主人公は全武器タイプを装備可能。
- 仲間はキャラクターごとに装備可能な武器タイプを設定する。
- 仲間の装備可能武器は原則として1キャラにつき2種類まで。

## 装備種別

### 武器

固定要素:

- ステータス補正
- アクティブスキル
  - 0個、1個、複数個のいずれも許可する。
  - 武器によってはアクティブスキルを持たない。
- 固定パッシブ
  - 任意。

ランダム要素:

- ステータス個体差
- ランダムパッシブ

### 防具

固定要素:

- ステータス補正
- 固定パッシブ

ランダム要素:

- ステータス個体差
- ランダムパッシブ

### アクセサリ

固定要素:

- ステータス補正
  - 任意。
- 固定パッシブ

ランダム要素:

- ステータス個体差
- ランダムパッシブ

## 基本ステータス

装備で扱う基本ステータスは以下の5種類とする。

- 攻撃
- 魔力
- 防御
- 素早さ
- 会心

HP/SPは装備の基本ステータスには含めない。

## 武器タイプ

- 剣
  - 斬属性。
  - バランス型。

- 短剣
  - 斬属性。
  - 素早さ・会心・状態異常寄り。

- 斧
  - 斬/打寄り。
  - 高火力・低速型。

- 槍
  - 突属性。
  - 安定した攻撃、隊列や先制補正と相性がよい。

- 弓
  - 突属性。
  - 後衛向け、命中・補助・状態異常寄り。

- 杖
  - 打/魔法寄り。
  - 魔法、回復、補助スキルと相性がよい。

## 主人公の武器

- 主人公は剣、短剣、斧、槍、弓、杖をすべて装備可能。
- 武器を変更することで役割が変わる。
- 武器固有アクティブスキルを活用できることを特徴にする。
- 仲間編成に合わせて不足役割を補う。
- 主人公専用の得意武器は現時点では設定しない。

## 仲間の武器タイプ例

- 物理アタッカー: 剣 / 斧
- 魔法アタッカー: 杖 / 短剣
- ヒーラー: 杖 / 弓
- タンク: 剣 / 槍
- サポーター: 弓 / 杖
- スピード型: 短剣 / 弓

## アクティブスキル

- アクティブスキルは武器のみが保持する。
- 武器によって、スキルなし、1個、複数個を設定できる。
- 武器を外すと、その武器由来のアクティブスキルは使用できなくなる。
- 主人公は武器を変更すると使用できるアクティブスキルも変化する。
- キャラクター固有スキルと武器アクティブスキルは、戦闘中のスキル一覧にまとめて表示する。
- ランダムアクティブスキルは採用しない。

## パッシブ

- 装備には固定パッシブとランダムパッシブを持たせる。
- 固定パッシブは装備マスターデータに定義し、装備すれば必ず有効になる。
- ランダムパッシブは入手・合成時に抽選される。
- ランダムパッシブにはLvを持たせる。
- 合成Lvが高いほど、高Lvパッシブが出現しやすくなる。

例:

```text
炎属性ダメージ+ Lv1
炎属性ダメージ+ Lv2
炎属性ダメージ+ Lv3
```

## ステータス個体差

装備強化は初期要件では採用しない。
`+1`, `+2` のような強化値は持たず、装備の性能は基本データと入手時の個体差で決まる。

- 同じ装備でも、入手・合成時にステータス個体差とランダムパッシブが抽選される。
- 個体差は周回内のみ有効。
- 周回終了時に装備はリセットされる。
- 装備図鑑はないため、個体差の記録は残さない。
- 基本性能は装備データで固定。
- ステータス個体差は追加補正として扱う。

### 抽選対象

- ランダム補正は、その装備が元々持つステータスのみを対象とする。
- 素早さのみ、全装備共通で個体差対象とする。
- 素早さ個体差により、軽量個体、重量個体などを表現する。

例:

```text
鉄の剣
攻撃 +12

抽選対象:
攻撃
素早さ
```

```text
旅人の服
防御 +5
素早さ +2

抽選対象:
防御
素早さ
```

```text
魔導のローブ
防御 +3
魔力 +8

抽選対象:
防御
魔力
素早さ
```

## EquipmentData

```text
equipmentId
name
description
iconSprite
equipmentType
weaponType
statModifiers
activeSkillIds
fixedPassiveIds
randomPassivePool
allowedRandomStatTypes
equippableBy
price
unsellable
sortOrder
```

### 項目

- `equipmentId`
  - 一意ID。

- `name`
  - 表示名。

- `description`
  - 説明文。

- `iconSprite`
  - 装備アイコンSprite参照。
  - 装備一覧、ショップ、合成結果、入手表示で使用する。

- `equipmentType`
  - `weapon`
  - `armor`
  - `accessory`

- `weaponType`
  - 武器の場合のみ使用する。
  - 剣 / 短剣 / 斧 / 槍 / 弓 / 杖。
  - 通常攻撃属性は武器タイプから決定する。

- `statModifiers`
  - 攻撃 / 魔力 / 防御 / 素早さ / 会心。

- `activeSkillIds`
  - 武器が持つアクティブスキル。
  - 武器以外では空にする。

- `fixedPassiveIds`
  - 固定パッシブ。

- `randomPassivePool`
  - ランダムパッシブ候補。
  - パッシブ種別と出現可能Lvを定義する。

- `allowedRandomStatTypes`
  - その装備に付与されうるステータス個体差候補。
  - 原則として `statModifiers` が持つステータスと素早さを対象にする。

- `equippableBy`
  - 装備可能キャラクター、または装備可能条件。

- `price`
  - 購入価格。

- `unsellable`
  - `true` の場合は売却不可。

- `sortOrder`
  - 装備一覧での表示順。

### EquipmentDataに持たせないもの

- `rarity`
  - レアリティは採用しない。

- `rarityBase`
  - レアリティは採用しない。

- `randomActiveSkillPool`
  - ランダムアクティブスキルは採用しない。

- `equipSoundEffectId`
  - 装備変更SEは画面または共通処理側で扱う。

- `obtainSoundEffectId`
  - 入手SEは入手処理側で扱う。

- `sellPrice`
  - 売却価格は購入価格の50%を基本とする。
