# ショップ

親: [06_装備合成ショップ.md](../06_装備合成ショップ.md)

## ショップ

ショップは準備・補助・救済のための機能とする。

- 日数は進まない。
- 所持金を使って購入する。
- 不要なアイテムや装備を売却できる。
- 商品はフェーズ進行で増える。
- 合成レベルとは直接連動しない。

### 商品解放

- 第1フェーズ
  - 初期商品。

- 第2フェーズ
  - 序盤強化商品を追加。

- 第3フェーズ
  - 中盤商品を追加。

- 第4フェーズ
  - 終盤準備用の商品を追加。

### 販売するもの

- 消耗品
- 基本装備
- 一部素材

### 基本的に販売しないもの

- 最上位装備
- レア装備
- 重要イベント用アイテム
- 希少素材の大量販売

### 在庫

- 消耗品は在庫無制限。
- ただしプレイヤーの消耗品所持上限は合計20個。
- 素材は在庫有限。
- 装備は在庫有限。
- 有限在庫はフェーズ開始時に補充される。
- 補充タイミングは11日目、21日目、31日目。
- 1日ごとの補充はしない。

### ShopItemData

ショップに並ぶ商品設定を表す。
商品本体の性能や価格は `ItemData` / `EquipmentData` を参照する。

```text
shopItemId
availablePhase
itemType
itemId
stockType
stockCount
sortOrder
```

#### 項目

- `shopItemId`
  - ショップ商品設定の一意ID。

- `availablePhase`
  - 商品が並び始めるフェーズ。
  - 第1〜第4フェーズ。

- `itemType`
  - `item`
  - `equipment`

- `itemId`
  - 商品として販売するアイテムIDまたは装備ID。

- `stockType`
  - `unlimited`
  - `limited`

- `stockCount`
  - 有限在庫数。
  - `stockType = limited` の場合に使う。

- `sortOrder`
  - ショップ一覧での表示順。

#### ShopItemDataに持たせないもの

- `priceOverride`
  - 価格は `ItemData` / `EquipmentData` の `price` を使う。

- `restockPhase`
  - 有限在庫の補充タイミングは11日目、21日目、31日目で固定する。

### 売却

- 消耗品を売却可能。
- 素材を売却可能。
- 装備を売却可能。
- 売却時は確認を出す。
- 基本は売却可能とし、`unsellable = true` のものだけ売却不可にする。
- `unsellable` が未設定、または `false` なら売却可能。
- 売却不可のものは売却リストに出さない、または選択不可表示にする。
- 買い戻しは初期要件ではなし。

売却不可にする候補:

- キー素材
  - 森の魔核
  - 遺跡の歯車
  - 古竜の結晶
- イベント報酬装備
- 初期装備
- 売ると進行やバランスに影響するもの

### 売却価格

```text
売却価格 = 購入価格 × 0.5
```

- 小数は切り捨て。
- 購入価格が設定されていない非売品は、売却価格を個別設定するか売却不可にする。
