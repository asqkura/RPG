# アイテム

親: [06_装備合成ショップ.md](../06_装備合成ショップ.md)

## アイテム分類

初期要件ではキーアイテムを作らない。
クエスト進行やイベント進行はフラグで管理する。

### 消耗品

- HP回復
- SP回復
- 毒回復
- 状態異常回復
- 煙玉

初期要件では以下を含めない。

- 戦闘不能回復
- HP/SP両方回復
- 攻撃上昇アイテム
- 防御上昇アイテム

### 素材

- 合成に使う。
- 合成レベルアップに使う。
- 売却可能にするかは別途決める。

### 装備

- 武器
- 防具
- アクセサリ

### キーアイテムなしの方針

- 扉の開放、条件達成、依頼進行などはフラグで表現する。
- プレイヤーに明示したい進行情報は、イベント文やクエスト説明で見せる。
- 将来的に必要になった場合のみ、キーアイテム分類を追加する。

## ItemData

消耗品と素材はアイテムデータとして扱う。
キーアイテムは初期要件では作らない。

```text
itemId
name
description
iconSprite
itemType
rank
price
unsellable
usableInBattle
usableInField
effects
sortOrder
useAnimationId
useSoundEffectId
```

### 項目

- `itemId`
  - 一意ID。

- `name`
  - 表示名。

- `description`
  - 説明文。

- `iconSprite`
  - アイテムアイコンSprite参照。
  - アイテム一覧、ショップ、合成結果、入手表示で使用する。

- `itemType`
  - `consumable`
  - `material`

- `rank`
  - 素材ランク。
  - ランク1〜4。
  - 消耗品では基本空にする。

- `price`
  - 購入価格。

- `unsellable`
  - `true` の場合は売却不可。

- `usableInBattle`
  - 戦闘中に使用可能か。
  - 素材では基本 `false`。

- `usableInField`
  - 探索中/キャンプで使用可能か。
  - 素材では基本 `false`。

- `effects`
  - 消耗品の効果。
  - HP回復、SP回復、毒解除、状態異常解除、逃走成功など。
  - 素材では基本空にする。

- `sortOrder`
  - アイテム一覧での表示順。

- `useAnimationId`
  - 使用時の演出ID。
  - 素材では基本空にする。

- `useSoundEffectId`
  - 使用時のSE ID。
  - 素材では基本空にする。

### ItemDataに持たせないもの

- `category`
  - 初期要件では持たせない。
  - 必要になった場合に、表示・絞り込み用の分類として追加する。

### 所持上限

- 消耗品は個別の `maxStack` を持たせない。
- 消耗品は全体で20個まで所持可能とする。
- 素材はスタック可能とし、初期要件では所持上限を設けない。

## 消耗品仕様

### 使用可能場面

消耗品は、アイテムごとに使用可能場面を持つ。

```text
usableInBattle: true / false
usableInField: true / false
```

使用場面の初期方針:

| 種類 | 戦闘中 | 探索中/キャンプ |
| --- | --- | --- |
| HP回復 | 可 | 可 |
| SP回復 | 可 | 可 |
| 毒回復 | 可 | 不可 |
| 状態異常回復 | 可 | 不可 |
| 煙玉 | 可 | 不可 |

毒、スタン、攻撃低下、防御低下、攻撃上昇、防御上昇は戦闘終了時に解除されるため、毒回復・状態異常回復は戦闘中のみ使用する。

### 所持制限

- 消耗品は合計20個まで所持可能。
- 同名消耗品は個数表示してよい。
- 所持上限判定は全消耗品の合計数で行う。
- 素材・装備はこの20個制限に含めない。
- 20個を超える場合は購入・取得できない、またはその場で破棄/入れ替え選択を行う。
