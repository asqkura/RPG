# 合成

親: [06_装備合成ショップ.md](../06_装備合成ショップ.md)

## 合成

装備入手の中心は合成とする。
クエストやうろつきで素材を集め、合成で武器、防具、アクセサリを作る。

### 合成の基本

- 合成では日数は進まない。
- 必要素材やお金を消費して装備・アイテムを作る。
- 作成した装備・アイテムは、その周回内の所持品として扱う。

### 合成レベル

- 名称は `合成レベル`。
- 合成レベルは `Lv1` から開始する。
- 最大 `Lv5`。
- 指定された素材やお金を支払うことでレベルアップする。
- 合成レベルアップでは日数は進まない。
- 合成レベルはレシピ解放には使用しない。
- 合成レベルは、より品質の高い装備を作りやすくする技術を表す。
- 合成レベルが上がるほど、ステータス個体差の上振れ率が高くなる。
- 合成レベルが上がるほど、高Lvランダムパッシブが抽選されやすくなる。
- 周回開始時は基本的に `Lv1` に戻る。
- テスト用、デバッグ用の初期データでは、動作確認を優先して合成Lvや所持素材を任意に付与してよい。

### 合成レベルの段階イメージ

- Lv1: 標準品質の個体が中心。
- Lv2: 少し上振れたステータス個体差が出やすくなる。
- Lv3: 有用なランダムパッシブやLv2パッシブが出やすくなる。
- Lv4: 高めのステータス個体差と高Lvパッシブが狙いやすくなる。
- Lv5: 最良個体やLv3パッシブを狙いやすくなる。

### 合成レベルアップ方針

- 合成Lvを上げるには素材とお金が必要。
- 通常素材に加えて、フェーズや進行に対応したキー素材を要求する。
- キー素材は主にメインクエスト、重要サブクエスト、強敵戦などで入手する。
- キー素材を集めることが、より良い装備個体を作る目的になる。
- 合成レベルアップ要求は、素材ランク合計ではなく具体的な素材名で指定する。
- Lv4までは自然に進めても届きやすい。
- Lv5は少し意識して素材集めをする必要がある。

### 素材カテゴリ

素材カテゴリは初期要件では `ItemData` に持たせない。
以下は素材名や用途を考えるための設計メモとする。

- 鉱石系
  - 武器、防具、金属系アクセサリに使う。

- 木材系
  - 弓、杖、軽装備、道具に使う。

- 皮/布系
  - 防具、軽装備、アクセサリに使う。

- 魔石系
  - 魔法装備、属性装備、アクセサリに使う。

- 薬草系
  - 回復アイテム、補助アイテム、状態異常回復に使う。

- キー素材
  - 合成レベルアップや重要装備の解放に使う。

### 素材ランク

素材ランクはランク1〜4とし、4フェーズに対応させる。

- ランク1
  - 第1フェーズ中心。
  - 合成Lv1〜2で使う。
  - 基本素材。

- ランク2
  - 第2フェーズ中心。
  - 合成Lv2〜3で使う。
  - 序盤強化素材。

- ランク3
  - 第3フェーズ中心。
  - 合成Lv3〜4で使う。
  - 中盤素材。

- ランク4
  - 第4フェーズ中心。
  - 合成Lv4〜5で使う。
  - 終盤・高性能装備素材。

### 素材名

素材名は仮とし、世界観が固まった段階で差し替えてよい。

| カテゴリ | R1 | R2 | R3 | R4 |
| --- | --- | --- | --- | --- |
| 鉱石系 | 鉄鉱石 | 鋼鉱石 | ミスリル鉱石 | 星銀鉱石 |
| 木材系 | 丈夫な木材 | 硬い木材 | 霊木材 | 古樹材 |
| 皮/布系 | 獣の皮 | 上質な革 | 魔獣の革 | 竜鱗布 |
| 魔石系 | 魔石の欠片 | 魔石 | 大魔石 | 星晶石 |
| 薬草系 | 薬草 | 癒し草 | 霊薬草 | 月光草 |

### 合成レベルアップ要求

合成レベルアップ要求は、個別のデータとして管理する。
UI表示用の名称、説明、アイコンも持たせる。

#### Lv1 → Lv2

- 鉄鉱石 x3
- 丈夫な木材 x2
- 獣の皮 x2
- 100G

#### Lv2 → Lv3

- 鋼鉱石 x3
- 硬い木材 x2
- 魔石の欠片 x3
- 森の魔核 x1
- 300G

#### Lv3 → Lv4

- ミスリル鉱石 x3
- 魔獣の革 x2
- 魔石 x3
- 遺跡の歯車 x1
- 700G

#### Lv4 → Lv5

- 星銀鉱石 x3
- 古樹材 x2
- 大魔石 x3
- 古竜の結晶 x1
- 1500G

### キー素材

- 森の魔核
  - 第2フェーズ相当。

- 遺跡の歯車
  - 第3フェーズ相当。

- 古竜の結晶
  - 第4フェーズ相当。

### SynthesisLevelUpRequirementData

```text
requirementId
displayName
description
iconSprite
currentLevel
targetLevel
materialCosts
moneyCost
sortOrder
```

#### 項目

- `requirementId`
  - 一意ID。

- `displayName`
  - 表示名。
  - 例: `合成Lv2へ強化`。

- `description`
  - 説明文。
  - レベルアップで増える作成対象や段階イメージを短く表示する。

- `iconSprite`
  - 合成Lvアップ項目のアイコンSprite参照。

- `currentLevel`
  - レベルアップ前の合成Lv。

- `targetLevel`
  - レベルアップ後の合成Lv。
  - 基本的に `currentLevel + 1` とする。

- `materialCosts`
  - 必要素材一覧。

- `moneyCost`
  - 必要なお金。

- `sortOrder`
  - 表示順。
