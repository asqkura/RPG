# 概要

## 位置づけ

このドキュメント群は、既存の `Docs/spec` 配下の仕様を前提にせず、ゼロベースで整理する新しい要件定義である。
既存ドキュメントは参考資料として扱う。

## ゲーム概要

イベントを進めることを主軸にしながら、戦闘で敵を倒し、素材を集め、装備を合成し、キャラクターを強化していく周回型RPG。

参考イメージはパワポケの裏サクセス系。
拠点から行動を選び、イベント、戦闘、報酬、成長を繰り返す。
1回のプレイですべてを回収するのではなく、複数周でエンディングやエピローグの記録を埋めていく。

## 基本コンセプト

- イベントと戦闘の比重は半々程度にする。
- ソーシャルゲーム的な期間限定イベントは採用しない。
- 1周の中で、どのクエストへ行くか、どこをうろつくか、誰を育てるかを選ばせる。
- 装備収集はエンディング条件ではなく、周回内の攻略・戦闘を有利にする楽しみにする。
- 周回引き継ぎは、エンディング・エピローグなどの記録に絞る。

## 初期要件に含めないもの

- 期間限定イベント
- 敵図鑑
- 装備図鑑
- アイテム図鑑
- 通常イベント回想
- 通常イベント既読スキップ
