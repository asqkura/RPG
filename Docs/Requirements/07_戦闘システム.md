# 戦闘システム

## 基本ルール

戦闘はターン制コマンドバトルとする。

- プレイヤーが各キャラクターの行動を選ぶ。
- 行動順は素早さを基準に決まる。
- 行動順はターンごとに再計算する。
- 素早さ上昇・低下などの効果は行動順に影響する。
- 戦闘結果に応じて経験値、所持金、素材などを得る。

## 戦闘コマンド

- 攻撃
- スキル
- アイテム
- 防御
- 逃げる

## 逃げる

- 戦闘中に撤退を試みるコマンド。
- 成功した場合、戦闘を終了して探索画面へ戻る。
- クエスト中の戦闘逃走は、クエスト失敗にはしない。
- 逃走成功時、その戦闘ノードは設定に従って処理済みまたは未処理になる。
- 逃走成功後、クエスト探索を継続できる。
- うろつき中の戦闘なら、イベント未達または中断扱い。
- 逃走成功時、その戦闘の経験値・お金・素材などは得られない。
- 逃走失敗時は敵の行動を受ける。
- ボス戦や重要戦闘では逃走不可にできる。

### 逃走成功率

```text
逃走成功率 = 70% + (味方平均素早さ - 敵平均素早さ) × 1%
最終成功率 = clamp(逃走成功率, 30%, 95%)
```

- 味方平均素早さは、戦闘可能な味方メンバーの平均値を使う。
- 敵平均素早さは、戦闘中の敵メンバーの平均値を使う。
- 逃走不可の戦闘では判定を行わない。
- 逃走成功補助アイテムを使う場合は、通常戦闘からの逃走を確定成功にできる。

## 敗北

- 通常戦闘で敗北しても周回は終了しない。
- 敗北したクエストまたはイベントは失敗扱いになる。
- その日の行動は消費される。
- 日数が1日進んでホームに戻る。
- 最終戦や特定重要戦闘だけは、敗北エンドや周回終了にしてもよい。

## HP/SP

- HPが0になると戦闘不能。
- 全員が戦闘不能になると敗北。
- SPはスキル使用時に消費する。
- 物理技、魔法的な技、補助技はSPでまとめて扱う。
- 同じクエスト・うろつき内で複数戦闘がある場合、HP/SPの消耗は引き継ぐ。
- クエスト・うろつきが終了してホームに戻ると、HP/SPは全回復する。
- 敗北時もホームに戻った時点で回復する。

## スキル

- スキルはSPを消費して使用する。
- 攻撃、回復、補助、弱体、状態異常などの効果を持てる。
- キャラクターごとの基本スキルはレベルアップで習得する。
- 装備由来のスキルは、装備中のみ使用できる。
- スキルは戦闘中のみ使用できる。
- キャンプや探索中にスキルは使用しない。

### スキル基本方針

- スキルには基本分類を持つ。
- スキルは `effects` として複数効果を持てる。
- 効果はデータに定義された順番で処理する。
- 吸血、ダメージ + 毒、攻撃 + 防御低下、回復 + 防御上昇などを表現できる。

### スキル分類

- `physicalAttack`
  - 物理攻撃。

- `magicAttack`
  - 魔法攻撃。

- `heal`
  - 回復。

- `buff`
  - 強化。

- `debuff`
  - 弱体。

- `status`
  - 状態異常。

### 効果タイプ

- `damage`
  - ダメージを与える。

- `heal`
  - HPを回復する。

- `buff`
  - 攻撃上昇、防御上昇など。

- `debuff`
  - 攻撃低下、防御低下など。

- `status`
  - 毒、スタンなど。

- `drain`
  - 与えたダメージの割合で自分を回復する。

- `cleanse`
  - 状態異常・弱体などを解除する。

### 効果処理順

- `effects` に定義された順番で処理する。
- ダメージ後に吸血、ダメージ後に毒付与などを表現できる。
- デバフを先に入れてからダメージ、というスキルも作れる。
- 処理順はスキルデータ側で明示する。

例:

```text
吸血:
effects:
  1. damage
  2. drain
```

```text
防御崩し:
effects:
  1. debuff 防御低下
  2. damage
```

```text
毒斬り:
effects:
  1. damage
  2. status 毒
```

### 対象指定

- スキル全体に `targetType` を持つ。
- 各効果は基本的に `target: default` を使う。
- 必要な効果だけ `target` を上書きできる。

`targetType` 例:

- `enemySingle`
- `enemyAll`
- `allySingle`
- `allyAll`
- `self`

`effect target` 例:

- `default`
  - スキル全体の対象を使う。

- `self`
  - 使用者自身。

- `target`
  - 選択対象。

- `allEnemies`
  - 敵全体。

- `allAllies`
  - 味方全体。

### drain

- `drain` 効果は単体攻撃スキルにのみ付与できる。
- 敵全体攻撃 + `drain` は初期要件では扱わない。
- 回復量は、対象1体に実際に与えた最終ダメージを基準にする。

```text
回復量 = 対象1体への最終ダメージ × drainRate
```

実際に与えたダメージには以下を含む。

- 防御軽減後
- 属性倍率後
- 隊列補正後
- 乱数後
- 会心後

### cleanse

初期の標準 `cleanse` は以下を解除する。

- 毒
- スタン
- 攻撃低下
- 防御低下

解除しないもの:

- 攻撃上昇
- 防御上昇

標準の `cleanseType` は `negativeOnly` とする。
将来的に敵のバフ解除を作る場合は、`positiveOnly` や `all` を検討する。

  - `damage`

## 状態異常・状態変化

初期状態異常・状態変化は以下に絞る。

- 毒
- スタン
- 攻撃低下
- 防御低下
- 攻撃上昇
- 防御上昇

状態異常・状態変化は戦闘中に発生し、戦闘終了時に基本解除される。
状態異常回復アイテムやスキルで解除できる。
装備やアクセサリで耐性を持たせられる。

### 継続管理

- 状態異常やバフ/デバフは、残り行動回数で管理する。
- 付与するスキルごとに `durationActions` を持つ。
- 対象が行動を終えるたびに `durationActions` を1減らす。
- `durationActions` が0になると解除される。
- スタンなどで行動不能になった場合も、行動をスキップした時点で1減らす。
- 戦闘終了時には基本解除される。

この方式は通常ターン制でもCTBでも使える。

HP/SPの消耗はクエスト中に引き継ぐが、状態異常・状態変化は戦闘をまたいで引き継がない。

### 毒

- 対象の行動終了時に毒ダメージを受ける。
- 毒ダメージは対象の最大HP割合で計算する。
- 毒の割合は、付与するスキルごとに設定する。
- 例: 最大HPの5%、8%、10%など。
- 毒ダメージには乱数を入れない。
- 毒ダメージでHPが0になった場合、戦闘不能になる。
- 敵も味方も同じルールとする。

### スタン

- スタン中の対象は、次の行動タイミングで行動できない。
- 行動をスキップした時点でスタンを解除する。
- 基本は `durationActions = 1`。
- 複数回行動不能のスタンは初期要件では扱わない。
- ボスや重要敵にはスタン耐性を持たせられる。

### 攻撃低下

- 対象の攻撃を20%下げる。
- 物理通常攻撃、物理スキルのダメージに影響する。
- 魔力には影響しない。

```text
攻撃低下中の攻撃 = 攻撃 × 0.8
```

### 防御低下

- 対象の防御を20%下げる。
- 物理・魔法どちらの被ダメージにも影響する。
- 防御軽減式に入る防御値を下げる。

```text
防御低下中の防御 = 防御 × 0.8
```

### 攻撃上昇

- 対象の攻撃を20%上げる。
- 物理通常攻撃、物理スキルのダメージに影響する。
- 魔力には影響しない。

```text
攻撃上昇中の攻撃 = 攻撃 × 1.2
```

### 防御上昇

- 対象の防御を20%上げる。
- 物理・魔法どちらの被ダメージにも影響する。

```text
防御上昇中の防御 = 防御 × 1.2
```

### 重ねがけ

- 同じ状態変化は重ねがけ不可。
- すでに同じ効果が付いている場合、効果量は増えない。
- 残り行動回数が長い方を採用する。
- 短い効果で長い効果を上書きしない。

例:

```text
攻撃上昇 残り3行動
→ 攻撃上昇 残り2行動を再付与
→ 残り3行動のまま
```

```text
防御低下 残り1行動
→ 防御低下 残り3行動を再付与
→ 残り3行動に更新
```

### 相殺

反対効果が付与された場合は、相殺して両方消える。

- 攻撃上昇中に攻撃低下を受けた場合
  - 攻撃上昇を解除する。
  - 攻撃低下は付与しない。

- 攻撃低下中に攻撃上昇を受けた場合
  - 攻撃低下を解除する。
  - 攻撃上昇は付与しない。

- 防御上昇と防御低下も同様。

### 付与成功率

状態異常や敵へのデバフは、スキル基本成功率と対象耐性で判定する。

```text
最終成功率 = clamp(スキル基本成功率 - 対象耐性, 0%, 100%)
```

- 0%なら絶対に付与されない。
- 100%なら必ず付与される。
- ボスや重要敵に完全耐性を持たせられる。
- イベントや特殊スキルで確定付与も可能。

### バフ/デバフ成功判定

- 味方への攻撃上昇・防御上昇
  - 必ず成功する。

- 敵への攻撃低下・防御低下
  - スキル基本成功率と対象耐性で判定する。

- 毒・スタン
  - スキル基本成功率と対象耐性で判定する。

- 敵が敵自身に使うバフ
  - 必ず成功する。

- 敵が味方側へ使うデバフ/状態異常
  - スキル基本成功率と対象耐性で判定する。

### 耐性種別

- 状態異常耐性
  - 毒
  - スタン

- 弱体耐性
  - 攻撃低下
  - 防御低下

例:

```text
毒付与スキル 基本成功率70%
対象の状態異常耐性20%
→ 最終成功率50%
```

```text
防御低下スキル 基本成功率80%
対象の弱体耐性30%
→ 最終成功率50%
```

## 属性

攻撃やスキルには属性を持たせられる。
敵には属性耐性や弱点を持たせられる。
装備やアクセサリで属性耐性を上げられる。

### 物理属性

- 斬
- 打
- 突

### 魔法属性

- 火
- 水
- 雷
- 風
- 光
- 闇

### 属性相性

- 弱点属性で攻撃すると与ダメージが増える。
- 耐性属性で攻撃すると与ダメージが減る。
- 弱点を突くと戦闘が楽になる。
- 弱点を突かないと勝てない設計にはしない。
- レベル、装備、スキル、アイテムでも攻略できる余地を残す。
- ボスや強敵では属性対策の重要度を少し高めてもよい。

## ダメージ計算

### 基本方針

- 防御は割合軽減型にする。
- 物理ダメージも魔法ダメージも、防御ステータスで軽減する。
- 精神・魔法防御のような別ステータスは初期要件では追加しない。
- 表示される攻撃・魔力・防御などは、装備補正込みの最終値とする。
- ダメージ計算では、表示されている最終ステータスを使う。
- 計算結果は最終的に整数へ丸める。

### 防御軽減

```text
軽減後ダメージ = 基礎威力 × 100 / (100 + 防御)
```

防御の効き方の目安:

```text
防御 0   → 100%
防御 50  → 約67%
防御 100 → 50%
防御 200 → 約33%
```

### 通常攻撃

通常攻撃は装備中の武器属性を参照する。
武器タイプで属性を固定せず、武器データ側に通常攻撃属性を持たせる。

```text
通常攻撃ダメージ =
攻撃
× 100 / (100 + 対象防御)
× 属性倍率
× 隊列補正
× 乱数
```

### スキルデータ

スキルには以下を持たせる。

- 参照ステータス
  - 攻撃
  - 魔力

- 倍率
  - 例: 1.2倍、1.8倍など。

- 属性
  - 斬 / 打 / 突 / 火 / 水 / 雷 / 風 / 光 / 闇

- SP消費

- 対象
  - 敵単体
  - 敵全体
  - 味方単体
  - 味方全体
  - 自分

- 効果
  - ダメージ
  - 回復
  - バフ
  - デバフ
  - 状態異常
  - 複合効果

### 物理スキル

```text
物理スキルダメージ =
攻撃 × スキル倍率
× 100 / (100 + 対象防御)
× 属性倍率
× 隊列補正
× 乱数
```

### 魔法スキル

```text
魔法スキルダメージ =
魔力 × スキル倍率
× 100 / (100 + 対象防御)
× 属性倍率
× 乱数
```

## 回復計算

回復スキルは、スキルごとに回復方式を持つ。
回復量には基本的に乱数を入れない。

### 固定値回復

```text
回復量 = 固定値
```

### ステータス参照回復

```text
回復量 = 固定値 + 参照ステータス × 回復倍率
```

### 割合回復

```text
回復量 = 対象最大HP × 回復割合
```

### 割合 + 固定値回復

```text
回復量 = 対象最大HP × 回復割合 + 固定値
```

### 使い分け

- 手当、応急処置、包帯
  - 割合回復。
  - ステータスなし。

- ヒール、癒しの光
  - 魔力参照回復。

- 薬品系スキル
  - 固定値回復、または割合 + 固定値。

## 会心

- 会心は通常攻撃と物理スキルに発生する。
- 魔法スキル、回復スキル、補助スキルには発生しない。
- 会心発生時、最終ダメージを1.5倍にする。
- 会心率はステータスとして表示する。
- 会心率は最大100%。
- 100%なら通常攻撃・物理スキルが確定会心になる。

## 乱数

ダメージ乱数は±10%とする。

```text
乱数 = 0.9 〜 1.1
```

- ダメージ計算の最後に乗算する。
- 同じ攻撃でも少しダメージが揺れる。
- 回復量には基本的に乱数を入れない。
- 毒などの固定ダメージにも基本的に乱数を入れない。

## 属性倍率

属性倍率は以下とする。

- 通常: `1.0`
- 弱点: `1.3`
- 耐性: `0.7`

弱点を突くと戦闘が楽になるが、属性を突かないと勝てないほどにはしない。

## 隊列補正

- 前衛からの攻撃: `1.0`
- 後衛からの弓・杖攻撃: `1.0`
- 後衛からの剣・短剣・斧・槍攻撃: `0.7`

対象:

- 通常攻撃
- 近接系の物理スキル

補足:

- 魔法スキルや回復スキルは、後衛でも低下しない。
- スキルごとに例外を持たせる余地は残す。
