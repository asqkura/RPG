# 敵と戦闘データ

## 基本方針

敵そのものの能力や行動は `EnemyData` に持たせる。
戦闘1回分の編成や背景、逃走可否は `BattleData` に持たせる。

クエストノードは `battleId` を参照し、実際の敵編成は `BattleData` 側で定義する。

## 敵行動

敵の行動パターンは、基本ランダム + 条件付き行動とする。

- 敵は行動候補リストを持つ。
- 通常時は行動候補から重み抽選で行動する。
- 条件付き行動は、行動ごとに優先実行か重み抽選候補かを設定できる。
- 雑魚敵はランダム中心。
- ボスや強敵は条件付き行動を持てる。

## 行動選択方式

敵の各行動に `selectionType` を持たせる。

### priority

- 条件を満たしたら優先実行する。
- 複数ある場合は優先度や重みで選ぶ。
- ボスの大技、瀕死時の回復、形態変化などに使う。

### weighted

- 条件を満たしている場合だけ重み抽選候補に入る。
- 通常攻撃、状態異常攻撃、補助行動などに使う。

## 行動選択フロー

1. 使用可能な行動候補を集める。
2. 条件を満たした `priority` 行動があれば優先選択する。
3. `priority` が複数ある場合は、優先度順または重みで決定する。
4. `priority` がなければ、`weighted` 行動から重み抽選する。
5. 何もなければ通常攻撃する。

## 行動条件

敵行動の条件には以下を使える。

- 自分のHPが一定割合以下。
- 味方側に毒が入っていない。
- プレイヤー側にバフがある。
- 自分に防御低下が入っている。
- 行動回数が一定以上。
- 特定ターン/特定回数。
- ランダム確率。

## 敵報酬

戦闘報酬は敵ごとにドロップ判定する。

- 敵ごとに経験値・お金・ドロップを持つ。
- 戦闘勝利時、倒した敵ごとに報酬を集計する。
- `BattleData` 側には基本的に報酬を持たせない。
- 特殊報酬はイベント効果や宝箱ノードで処理する。

### 敵ごとの報酬

- 経験値
  - 基本確定。

- お金
  - 基本確定。

- 素材
  - 主なドロップ。
  - ドロップ率を持つ。

- アイテム
  - 低確率、または特定敵のみ。

- 装備
  - 基本なし。
  - 特殊敵やイベント戦闘のみ例外的に扱う。

### 特殊報酬

以下は敵ドロップではなく、クエストクリアイベント、イベント効果、宝箱ノードで処理する。

- キー素材
- 仲間加入
- 特別素材
- 装備
- まとまったお金

## EnemyData

```text
enemyId
name
description
level
stats
attributes
statusResistance
debuffResistance
skills
actions
exp
money
drops
enemySprite
displayScale
displayOffset
defaultAttackSkillId
```

### 項目

- `enemyId`
  - 一意ID。

- `name`
  - 表示名。

- `description`
  - 説明文。

- `level`
  - 敵レベル。

- `stats`
  - HP、SP、攻撃、魔力、防御、素早さ、会心率。

- `attributes`
  - 弱点・耐性属性。

- `statusResistance`
  - 毒・スタンに対する状態異常耐性。

- `debuffResistance`
  - 攻撃低下・防御低下に対する弱体耐性。

- `skills`
  - 使用可能スキルID一覧。

- `actions`
  - 行動候補一覧。

- `exp`
  - 勝利時に得る経験値。

- `money`
  - 勝利時に得るお金。

- `drops`
  - ドロップ候補。

- `enemySprite`
  - 敵グラフィックSprite参照。
  - 戦闘画面で表示する敵画像を参照する。

- `displayScale`
  - 戦闘画面での表示倍率。

- `displayOffset`
  - 戦闘画面での表示位置補正。

- `defaultAttackSkillId`
  - 通常攻撃として使うスキルID。
  - 行動候補が選べない場合のフォールバックにも使う。

### EnemyDataに持たせないもの

- `isBoss`
  - ボス判定は `BattleData` 側に持たせる。
  - 同じ敵を通常戦とボス戦の両方で使えるようにする。

- `deathAnimationId`
  - 初期要件では共通演出を使う。

- `hitEffectId`
  - 初期要件では共通演出を使う。

- `sortOrder`
  - 敵図鑑や敵一覧UIを作らないため初期要件では持たせない。

## EnemyAction

```text
skillId
selectionType
priority
weight
conditions
```

### 項目

- `skillId`
  - 使用するスキルID。

- `selectionType`
  - `priority`
  - `weighted`

- `priority`
  - 優先行動同士の順序制御に使う。

- `weight`
  - 重み抽選に使う。

- `conditions`
  - 行動条件。

## EnemyDrop

```text
itemId
dropRate
minCount
maxCount
```

### 項目

- `itemId`
  - ドロップする素材・アイテム・例外的な装備のID。

- `dropRate`
  - ドロップ率。

- `minCount`
  - 最小個数。

- `maxCount`
  - 最大個数。

## BattleData

```text
battleId
name
enemyEntries
battleBackgroundSprite
battleBgmId
canEscape
escapeCountsAsClear
escapeSuccessItemAllowed
isBoss
gameOverOnDefeat
defeatResultType
victoryEventId
defeatEventId
```

### 項目

- `battleId`
  - 一意ID。

- `name`
  - 戦闘表示名。

- `enemyEntries`
  - 敵編成。

- `battleBackgroundSprite`
  - 戦闘背景Sprite参照。

- `battleBgmId`
  - 戦闘BGM ID。

- `canEscape`
  - 逃走可能か。

- `escapeCountsAsClear`
  - 逃走成功時に、戦闘ノードを処理済みにするか。

- `escapeSuccessItemAllowed`
  - 煙玉などの逃走成功補助アイテムを使用可能か。

- `isBoss`
  - ボス戦か。

- `gameOverOnDefeat`
  - 敗北時に周回終了や敗北エンドへ進むか。

- `defeatResultType`
  - 敗北時の扱い。
  - `questFailure`
  - `eventFailure`
  - `ending`
  - `none`

- `victoryEventId`
  - 勝利時イベントID。任意。

- `defeatEventId`
  - 敗北時イベントID。任意。

### BattleDataに持たせないもの

- `turnLimit`
  - ターン制限戦闘は初期要件では扱わない。

- `startEventId`
  - 戦闘前イベントはイベント側からBattleDataを呼ぶ形で扱う。

## BattleEnemyEntry

```text
enemyId
count
position
```

### 項目

- `enemyId`
  - 出現する敵ID。

- `count`
  - 出現数。

- `position`
  - 表示位置や隊列上の位置。
