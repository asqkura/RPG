# エンディングと記録

## エンディング分岐

エンディング分岐は以下を主軸にする。

- メインイベント進行度
- キャラクターイベント達成
- 重要敵・ボスの撃破
- 選択肢・フラグ

## エンディング構造

エンディングは本筋エンド1つ + 追加エピローグ複数可とする。

- 41日目の最終イベント後、まず本筋エンドを1つ表示する。
- その後、条件を満たした追加エピローグを順に表示する。
- 1周で複数のキャラクターエピローグや後日談を解放してよい。
- 表示済みのエンド・エピローグは記録に登録される。

## 本筋エンド

この中から、その周回の結果として1つ表示する。

- 未達エンド
- 通常エンド
- 良エンド
- 真エンド
- 敗北エンド

## 追加エピローグ

条件を満たしていれば複数表示できる。

- キャラクターエピローグ
- 特定NPCの後日談
- 特定フラグ達成エピローグ
- 仲間や勢力ごとの結末

## 判定イメージ

- メイン進行度0〜1: 未達エンド候補。
- メイン進行度2: 通常エンド候補。
- メイン進行度3: 良エンド候補。
- メイン進行度4: 真エンド候補。
- 最終戦や重要戦闘で敗北した場合: 敗北エンド候補。
- キャラクターイベントを最終段階まで進め、必要フラグを満たしている場合: 追加エピローグ候補。

## 基本的に主条件にしないもの

- 特定装備の所持
- 特定アイテムの所持
- レア装備収集率

## 図鑑機能

図鑑機能は初期要件に含めない。

- 敵図鑑は作らない。
- 装備図鑑は作らない。
- アイテム図鑑は作らない。
- 周回記録はエンディング達成記録とエピローグ閲覧記録を中心にする。
- 装備・アイテム・素材は、その周回内の攻略要素として扱う。
