# UI基本方針と画面一覧

親: [12_UI画面と遷移.md](../12_UI画面と遷移.md)

## 基本方針

主要操作はマウス操作を前提にする。
各画面は、ホーム、探索、戦闘、キャンプ、システム系に大きく分ける。

このドキュメントでは画面の存在と主な入口を定義し、細かいレイアウトは別途画面仕様で扱う。
