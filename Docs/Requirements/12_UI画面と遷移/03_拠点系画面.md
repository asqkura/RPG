# 拠点系画面

親: [12_UI画面と遷移.md](../12_UI画面と遷移.md)

## 拠点系画面

### クエスト選択画面

- 解放済みクエストを一覧表示する。
- クエストの概要、推奨難度、再挑戦可否、クリア状態を表示する。
- クエストを選択すると確認後にクエスト探索画面へ進む。
- クエスト開始時に日数を消費する。

表示する情報:

- クエスト名
- クエスト説明
- クエスト状態
- 難度
- 再挑戦可否
- 失敗時に再挑戦不可かどうか
- 日数を消費すること
- 開始確認ダイアログ

表示しない情報:

- 敵編成の詳細
- ノード全体構造
- 正確な報酬一覧
- 分岐条件の詳細

### うろつき選択画面

- 解放済みのうろつき場所を一覧表示する。
- 場所を選択すると確認後にイベント判定へ進む。
- うろつき開始時に日数を消費する。

表示する情報:

- 場所名
- 場所の短い説明

表示しない情報:

- 発生イベント名
- 発生条件の詳細
- 発生確率
- 未発生イベント数
- 関連キャラのヒント
- エピローグ条件

### 合成画面

- 合成カテゴリを選択する。
- 登録済みレシピを表示する。
- 素材とお金が足りる場合のみ合成を実行できる。
- 合成では日数は進まない。

表示する情報:

- 合成カテゴリ
  - 消耗品
  - 武器
  - 防具
  - アクセサリー
  - その他
- 現在の合成Lv
- レシピ一覧
- 作成物の名前
- 作成物のアイコン
- 作成物の説明
- 必要素材
- 必要金額
- 素材の所持数/必要数
- 作成可否
- 作成後の消耗品所持数
- 合成確認ダイアログ
  - 初期要件では必須にしない。
  - 導入する場合は、合成実行前に作成物、必要素材、消費金額、現在所持数、作成後所持数を表示する。

装備レシピで表示する情報:

- 基本性能
- 装備可能者、または装備可能武器種
- 武器アクティブスキル
- 固定パッシブ
- ステータス個体差が付く可能性
- ランダムパッシブが付く可能性

その他カテゴリで表示する情報:

- 合成レベルアップ項目
- レベルアップ後の合成Lv
- 必要素材
- 必要金額
- 素材とお金が足りる場合のみ実行できること

表示しない情報:

- ステータス個体差の詳細抽選テーブル
- ランダムパッシブ候補の全リスト
- パッシブLvの詳細抽選率

合成完了後は、合成結果ポップアップを表示する。

合成結果ポップアップに表示する情報:

- 作成物の名前
- 作成物のアイコン
- ステータス個体差
- 付与されたランダムパッシブ
- ランダムパッシブLv

消耗品合成では、ステータス個体差、ランダムパッシブ、パッシブLvは表示しない。
装備合成では、抽選後の確定結果として表示する。
消費した素材とお金は、初期要件では合成結果ポップアップに表示しなくてよい。

### ショップ画面

- 商品購入と売却を行う。
- 消耗品、素材、装備を扱う。
- 購入・売却では日数は進まない。

表示する情報:

- 所持金
- タブ
  - 購入
  - 売却
- 商品カテゴリ
  - 消耗品
  - 素材
  - 装備
- 商品名
- アイコン
- 説明
- 価格
- 在庫数
- 所持数
- 購入可否
- 売却価格
- 売却不可表示
- 購入/売却確認ダイアログ

装備商品で表示する情報:

- 装備種別
- 基本性能
- 装備可能者、または装備可能武器種
- 武器アクティブスキル
- 固定パッシブ

表示しない情報:

- 店売り装備のステータス個体差抽選テーブル
- ランダムパッシブ抽選テーブル
- 売却不可アイテムの内部理由

売却不可の所持品は売却リストに表示する。
ただし選択不可にし、売却不可ラベルを表示する。

### 編成画面

- 戦闘参加メンバーと控えを設定する。
- 主人公は固定参加とする。
- 仲間の並びや参加枠を変更できる。
- 日数は進まない。
- 編成画面では前衛/後衛を変更しない。
- 前衛/後衛の変更は隊列画面で行う。

表示する情報:

- 主人公
- 加入済み仲間一覧
- 戦闘参加枠
- 控え枠
- 各キャラクターの名前
- Lv
- HP/SP
- 簡易ステータス
  - 攻撃
  - 魔力
  - 防御
  - 素早さ
- 装備中の武器
- 役割メモ
- 入れ替え操作

表示しない情報:

- 未加入キャラクター
- 前衛/後衛の変更操作
- 詳細なイベント進行度
- エピローグ条件
- 装備の全詳細
- スキル詳細一覧

### キャンプ画面

- アイテム、装備、ステータス、隊列へ遷移する共通メニュー。
- ホームからも探索中からも開ける。
- キャンプを開いても日数は進まない。
