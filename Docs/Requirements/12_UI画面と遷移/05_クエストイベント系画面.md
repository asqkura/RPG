# クエスト・イベント系画面

## クエスト・イベント系画面

### クエスト探索画面

- ノードマップを表示する。
- 現在ノード、接続先ノード、処理済み状態を表示する。
- ノード選択により、イベント、戦闘、宝箱、終了へ進む。
- 探索中はキャンプ画面を開ける。

表示する情報:

- ノードマップ
- 現在ノード
- 移動可能な接続先
- ノード種別アイコン
  - イベント
  - 戦闘
  - 宝箱
  - 終了
- 処理済みノード
- キャンプボタン
- 戻れない/進むのみなどの移動制限

表示しない情報:

- クエスト名
- 未到達ノードの詳細内容
- 敵編成の詳細
- 宝箱の中身
- 分岐条件の内部フラグ名
- クリア後イベントの内容

ノード種別はアイコンで表示する。
ただし、敵編成や宝箱の中身などの詳細は、該当ノードを処理するまで表示しない。

### イベント画面

- イベント本文、選択肢、結果を表示する。
- イベント効果に応じてフラグ、報酬、加入、戦闘開始などを処理する。
- イベント中は手動セーブ不可。

表示する情報:

- 背景
- 話者名
- 本文
- 吹き出し
- キャラクター立ち絵
- 選択肢
- 入手/消費/加入などの結果表示
- 次へボタン
- 設定ボタン

操作:

- クリックで文章送り。
- 選択肢クリックで決定する。
- イベント中に設定画面を開ける。
- イベント中のセーブ/ロードは不可。
- イベントスキップは初期要件では扱わない。

表示しない情報:

- イベントID
- フラグ名
- 発生条件
- 好感度や内部値
- 未選択肢の結果
- イベント既読状態

立ち絵がないキャラクターは、立ち絵なし表示を許容する。

### 戦闘画面

- ターン制コマンドバトルを行う。
- 攻撃、スキル、アイテム、防御、逃げるを選択する。
- 戦闘中は手動セーブ不可。

表示する情報:

- 味方一覧
  - 名前
  - HP
  - SP
  - 状態異常/状態変化
- 敵一覧
  - 敵グラフィック
  - 敵名
  - HPゲージ
  - 状態異常/状態変化
- 行動順
- コマンド
  - 攻撃
  - スキル
  - アイテム
  - 防御
  - 逃げる
- 選択中コマンドの説明
- スキル一覧
  - 消費SP
  - 対象
  - 簡単な効果
- アイテム一覧
  - 所持数
  - 簡単な効果
- 戦闘ログ

表示しない情報:

- 敵HPの数値
- 敵の正確なステータス
- 敵の行動テーブル
- 敵のドロップ率
- ダメージ計算式
- 内部成功率

敵HPは数値ではなくゲージのみで表示する。

### 報酬・結果表示方針

- 報酬表示専用画面は初期要件では作らない。
- クエスト/うろつき終了用のリザルト画面は初期要件では作らない。
- 戦闘勝利、宝箱、イベント報酬で得た内容は、イベント本文または短い通知で表示する。
- クエスト終了結果や報酬は、必要に応じて終了イベント内で表示する。
- 終了処理後は、日付進行とオートセーブを行いホームへ戻る。

表示しない情報:

- 獲得報酬の合計リザルト
- 敵ごとのドロップ率
- 報酬判定の内訳
- 未取得報酬
- 内部フラグ
