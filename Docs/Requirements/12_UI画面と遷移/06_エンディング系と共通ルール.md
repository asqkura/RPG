# エンディング系画面と共通ルール

親: [12_UI画面と遷移.md](../12_UI画面と遷移.md)

## エンディング系画面

### エンディング画面

- 本筋エンディングを表示する。
- 未達、通常、良、真、敗北などの結果を扱う。

### エピローグ画面

- 条件を満たした追加エピローグを表示する。
- 複数条件を満たした場合は複数表示してよい。

### 周回結果画面

- 周回で到達したエンディング、表示されたエピローグ、簡単な結果を表示する。
- 永続セーブデータへ記録する。
- 表示後、タイトルまたは新規周回開始へ遷移する。

## 戻る操作

- 各サブ画面は、基本的に開いた元の画面へ戻る。
- ホームから開いた画面はホームへ戻る。
- 探索中にキャンプを開いた場合は、探索画面へ戻る。
- イベント中、戦闘中は任意の戻る操作で中断しない。

## セーブ不可画面

以下の画面では手動セーブ不可とする。

- クエスト探索画面
- イベント画面
- 戦闘画面
- エンディング画面
- エピローグ画面
- 周回結果画面
