# キャンプ内画面

親: [12_UI画面と遷移.md](../12_UI画面と遷移.md)

## キャンプ内画面

### アイテム画面

- 所持消耗品を表示する。
- 使用可能場面に応じて使用できる。
- 素材は確認用として表示してよい。

表示する情報:

- タブ
  - 消耗品
  - 素材
- アイテム名
- アイコン
- 説明
- 所持数

消耗品で表示する情報:

- 使用可否
- 使用対象
- 使用確認
- 消耗品所持上限
- 効果
  - HP回復
  - SP回復
  - 毒回復
  - 状態異常回復
  - 逃走成功
- 使用可能場面
  - 戦闘中
  - 探索中/キャンプ

素材で表示する情報:

- 素材カテゴリ
- 素材ランク
- 主な用途
- 所持数

素材は確認用に表示する。
素材はアイテム画面から使用しない。

表示しない情報:

- 素材の全レシピ逆引き
- 入手場所の詳細
- 売却価格
- 内部効果ID

### 装備画面

- キャラクターごとの装備を変更する。
- 武器、防具、アクセサリーを扱う。
- 装備中に使用可能になるスキルも確認できる。

表示する情報:

- キャラクター一覧
- 選択中キャラクター
- 装備スロット
  - 武器
  - 防具
  - アクセサリー1
  - アクセサリー2
- 所持装備一覧
- 装備名
- アイコン
- 効果リスト
  - 基本性能
  - ステータス個体差
  - 武器アクティブスキル
  - 固定パッシブ
  - ランダムパッシブ
- 装備可否
- 装備変更後のステータス差分
- 他キャラクターが装備中かどうか

表示しない情報:

- 装備の入手元
- ステータス個体差の詳細抽選テーブル
- ランダムパッシブ抽選テーブル
- 未所持装備
- 他キャラクターの詳細ステータス
- 内部個体ID
- 売却不可/重要装備表示

他キャラクターが装備中の装備も付け替え可能とする。
その場合は「誰が装備中か」を表示し、確認後に付け替える。

### ステータス画面

- キャラクターの現在ステータスを表示する。
- 装備補正込みの最終値を表示する。
- 属性耐性、状態異常耐性、弱体耐性も確認できる。

表示する情報:

- キャラクター一覧
- 選択中キャラクター
- 名前
- Lv
- 経験値
- HP/SP
- 攻撃
- 魔力
- 防御
- 素早さ
- 会心率
- 前衛/後衛
- 装備中の武器、防具、アクセサリー
- 使用可能スキル
  - 固有スキル
  - 武器アクティブスキル
- スキル名
- スキル説明
- 消費SP
- 対象
- 装備パッシブ
- 属性耐性
- 状態異常耐性
- 弱体耐性

表示しない情報:

- 未加入キャラクター
- エピローグ条件
- 内部ID
- 詳細な経験値計算式
- 隠しフラグ

### 隊列画面

- 各キャラクターの前衛/後衛を設定する。
- 戦闘参加メンバーの隊列を確認・変更する。
- 戦闘参加メンバーのみを表示する。
- 控えメンバーは表示しない。
- 前衛は最低1人必要とする。
- 4人全員前衛は可能。
- 4人全員後衛は不可。

表示する情報:

- 戦闘参加メンバー
- 前衛枠
- 後衛枠

表示しない情報:

- 控えメンバー
- 未加入キャラクター
- 役割メモ
- HP/SP
- 装備中の武器
- 詳細ステータス
- スキル詳細
- 敵から狙われる内部確率
- 隊列補正の詳細計算式
