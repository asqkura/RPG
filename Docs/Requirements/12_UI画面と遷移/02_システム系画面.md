# システム系画面

親: [12_UI画面と遷移.md](../12_UI画面と遷移.md)

## 画面入口

### タイトル画面

タイトル画面から以下へ遷移する。

- はじめから
  - 新規周回を開始し、ホーム画面へ進む。

- つづきから
  - ロード画面を開く。

- アルバム
  - アルバム画面を開く。

- 設定
  - 設定画面を開く。

- ゲーム終了
  - ゲームを終了する。

表示する情報:

- はじめから
- つづきから
- アルバム
- 設定
- ゲーム終了

## ロード画面

表示する情報:

- 手動セーブ3枠
- オートセーブ1枠
- 現在日数
- セーブ日時
- 空スロット表示
- ロード確認

表示しない情報:

- 所持金
- メイン進行度
- パーティ概要
- 詳細なクエスト状態
- 内部フラグ

## セーブ画面

表示する情報:

- 手動セーブ3枠
- 現在日数
- セーブ日時
- 空スロット表示
- 上書き確認
- セーブ完了通知

表示しない情報:

- 所持金
- オートセーブ枠への手動保存
- 内部フラグ
- 詳細な所持品一覧

### ホーム画面

ホーム画面から以下へ遷移する。

表示する情報:

- 現在日数
- ホームメニュー
- 設定ボタン
- 選択中メニューの説明文

表示しない情報:

- 所持金
- 残り日数
- 現在フェーズ
- パーティ概要
- メイン進行度
- 次の節目までの日数

- クエスト
  - クエスト選択画面を開く。

- うろつき
  - うろつき選択画面を開く。

- 合成
  - 合成画面を開く。

- ショップ
  - ショップ画面を開く。

- 編成
  - 編成画面を開く。

- キャンプ
  - キャンプ画面を開く。

- セーブ
  - セーブ画面を開く。

- 設定
  - 補助ボタンまたは共通システムメニューから設定画面を開く。
