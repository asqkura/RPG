# 周回と進行

## 周回構造

- 1周は40日。
- 1日は1行動で構成する。
- 通常行動期間は1日目〜40日目。
- 40日目の行動終了後に一度ホームへ戻り、41日目の朝に最終イベントへ進む。
- 41日目は通常行動を選べない。
- 最終イベントでは、その周回中の行動結果に応じてエンディングが分岐する。
- 日数切れは即ゲームオーバーではなく、エンディング判定として扱う。

## 進行フェーズ

- 第1フェーズ: 1〜10日目
  - 基本導入。
  - 初期仲間。
  - 低難度クエスト。
  - うろつき場所の基本解放。
  - 合成Lv1〜2相当。

- 第2フェーズ: 11〜20日目
  - 仲間加入が増える。
  - サブクエスト拡張。
  - キャラクターイベント開始。
  - 合成Lv2〜3相当。

- 第3フェーズ: 21〜30日目
  - メインイベントが大きく進む。
  - 中〜高難度クエスト。
  - キャラクターイベントの分岐。
  - 合成Lv3〜4相当。

- 第4フェーズ: 31〜40日目
  - 終盤準備。
  - 重要ボス。
  - エンディング条件回収。
  - 合成Lv4〜5相当。

- 41日目
  - 最終イベント。
  - エンディング判定。

## 節目イベント

節目イベントは各フェーズ開始時に発生する。

- 1日目: 導入イベント、初期メインクエスト解放。
- 11日目: 第2フェーズ開始イベント、新しいメインクエストやうろつき場所の解放。
- 21日目: 第3フェーズ開始イベント、本筋の転換点、中盤以降のメインクエスト解放。
- 31日目: 第4フェーズ開始イベント、終盤突入、最終イベントに関わる条件提示や高難度クエスト解放。
- 41日目: 最終イベント、エンディング判定。

## メイン進行度

メイン進行度は0〜4の5段階で管理する。

- 進行度0: 導入のみ。メインクエスト未達成。
- 進行度1: 第1メインクエスト達成。
- 進行度2: 第2メインクエスト達成。
- 進行度3: 第3メインクエスト達成。
- 進行度4: 最終条件達成。真エンド候補に入れる状態。

41日目のエンディング判定では、メイン進行度を主条件の1つとして使う。

## 日数・行動ルール

- 表示は `1日目`、`2日目` のようにする。
- 日数はイベント発生条件、解放条件、ストーリー進行、キャラクターイベントに使う。
- 基本的に日数制限による即ゲームオーバーは採用しない。
- 特定イベントのみ、期限や日数条件を持たせる余地は残す。

### 日数を進める行動

- クエスト
- うろつき

### 日数を進めない行動

- 合成
- ショップ
- 編成
- キャンプ
- セーブ
- 設定
