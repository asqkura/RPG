# UI画面と遷移

## 基本方針

主要操作はマウス操作を前提にする。
各画面は、ホーム、探索、戦闘、キャンプ、システム系に大きく分ける。

このドキュメントでは画面の存在と主な入口を定義し、細かいレイアウトは別途画面仕様で扱う。

## 画面一覧

### システム系

- タイトル画面
- ロード画面
- セーブ画面
- 設定画面

### 拠点系

- ホーム画面
- クエスト選択画面
- うろつき選択画面
- 合成画面
- ショップ画面
- 編成画面
- キャンプ画面

### キャンプ内画面

- アイテム画面
- 装備画面
- ステータス画面
- 隊列画面

### クエスト・イベント系

- クエスト探索画面
- イベント画面
- 戦闘画面

### エンディング系

- エンディング画面
- エピローグ画面
- 周回結果画面

## 画面入口

### タイトル画面

タイトル画面から以下へ遷移する。

- はじめから
  - 新規周回を開始し、ホーム画面へ進む。

- つづきから
  - ロード画面を開く。

- アルバム
  - アルバム画面を開く。

- 設定
  - 設定画面を開く。

- ゲーム終了
  - ゲームを終了する。

表示する情報:

- はじめから
- つづきから
- アルバム
- 設定
- ゲーム終了

## ロード画面

表示する情報:

- 手動セーブ3枠
- オートセーブ1枠
- 現在日数
- セーブ日時
- 空スロット表示
- ロード確認

表示しない情報:

- 所持金
- メイン進行度
- パーティ概要
- 詳細なクエスト状態
- 内部フラグ

## セーブ画面

表示する情報:

- 手動セーブ3枠
- 現在日数
- セーブ日時
- 空スロット表示
- 上書き確認
- セーブ完了通知

表示しない情報:

- 所持金
- オートセーブ枠への手動保存
- 内部フラグ
- 詳細な所持品一覧

### ホーム画面

ホーム画面から以下へ遷移する。

表示する情報:

- 現在日数
- 所持金
- ホームメニュー
- 設定ボタン
- 選択中メニューの説明文

表示しない情報:

- 残り日数
- 現在フェーズ
- パーティ概要
- メイン進行度
- 次の節目までの日数

- クエスト
  - クエスト選択画面を開く。

- うろつき
  - うろつき選択画面を開く。

- 合成
  - 合成画面を開く。

- ショップ
  - ショップ画面を開く。

- 編成
  - 編成画面を開く。

- キャンプ
  - キャンプ画面を開く。

- セーブ
  - セーブ画面を開く。

- 設定
  - 補助ボタンまたは共通システムメニューから設定画面を開く。

## 拠点系画面

### クエスト選択画面

- 解放済みクエストを一覧表示する。
- クエストの概要、推奨難度、再挑戦可否、クリア状態を表示する。
- クエストを選択すると確認後にクエスト探索画面へ進む。
- クエスト開始時に日数を消費する。

表示する情報:

- クエスト名
- クエスト説明
- クエスト状態
- 難度
- 再挑戦可否
- 失敗時に再挑戦不可かどうか
- 日数を消費すること
- 開始確認ダイアログ

表示しない情報:

- 敵編成の詳細
- ノード全体構造
- 正確な報酬一覧
- 分岐条件の詳細

### うろつき選択画面

- 解放済みのうろつき場所を一覧表示する。
- 場所を選択すると確認後にイベント判定へ進む。
- うろつき開始時に日数を消費する。

表示する情報:

- 場所名
- 場所の短い説明

表示しない情報:

- 発生イベント名
- 発生条件の詳細
- 発生確率
- 未発生イベント数
- 関連キャラのヒント
- エピローグ条件

### 合成画面

- 合成カテゴリを選択する。
- 解放済みレシピを表示する。
- 素材とお金が足りる場合のみ合成を実行できる。
- 合成では日数は進まない。

表示する情報:

- 合成カテゴリ
  - 消耗品
  - 武器
  - 防具
  - アクセサリー
- 現在の合成Lv
- レシピ一覧
- 作成物の名前
- 作成物のアイコン
- 作成物の説明
- 必要素材
- 必要金額
- 素材の所持数/必要数
- 作成可否
- 作成後の消耗品所持数
- 合成確認ダイアログ

装備レシピで表示する情報:

- 基本性能
- 装備可能者、または装備可能武器種
- 固定スキル
- ランダム性能が付く可能性
- レアリティ抽選があること

表示しない情報:

- レアリティの正確な抽選確率
- ランダム補正の詳細テーブル
- ランダムスキル候補の全リスト

合成完了後は、合成結果ポップアップを表示する。

合成結果ポップアップに表示する情報:

- 作成物の名前
- 作成物のアイコン
- 作成物のレアリティ
- 付与されたランダム補正
- 付与されたランダムスキル
- 消費した素材
- 消費したお金

消耗品合成では、レアリティ、ランダム補正、ランダムスキルは表示しない。
装備合成では、抽選後の確定結果として表示する。

### ショップ画面

- 商品購入と売却を行う。
- 消耗品、素材、装備を扱う。
- 購入・売却では日数は進まない。

表示する情報:

- 所持金
- タブ
  - 購入
  - 売却
- 商品カテゴリ
  - 消耗品
  - 素材
  - 装備
- 商品名
- アイコン
- 説明
- 価格
- 在庫数
- 所持数
- 購入可否
- 売却価格
- 売却不可表示
- 購入/売却確認ダイアログ

装備商品で表示する情報:

- 装備種別
- 基本性能
- 装備可能者、または装備可能武器種
- 固定スキル

表示しない情報:

- 店売り装備のレアリティ抽選確率
- ランダム補正テーブル
- 売却不可アイテムの内部理由

売却不可の所持品は売却リストに表示する。
ただし選択不可にし、売却不可ラベルを表示する。

### 編成画面

- 戦闘参加メンバーと控えを設定する。
- 主人公は固定参加とする。
- 仲間の並びや参加枠を変更できる。
- 日数は進まない。
- 編成画面では前衛/後衛を変更しない。
- 前衛/後衛の変更は隊列画面で行う。

表示する情報:

- 主人公
- 加入済み仲間一覧
- 戦闘参加枠
- 控え枠
- 各キャラクターの名前
- Lv
- HP/SP
- 簡易ステータス
  - 攻撃
  - 魔力
  - 防御
  - 素早さ
- 装備中の武器
- 役割メモ
- 入れ替え操作

表示しない情報:

- 未加入キャラクター
- 前衛/後衛の変更操作
- 詳細なイベント進行度
- エピローグ条件
- 装備の全詳細
- スキル詳細一覧

### キャンプ画面

- アイテム、装備、ステータス、隊列へ遷移する共通メニュー。
- ホームからも探索中からも開ける。
- キャンプを開いても日数は進まない。

## キャンプ内画面

### アイテム画面

- 所持消耗品を表示する。
- 使用可能場面に応じて使用できる。
- 素材は確認用として表示してよい。

表示する情報:

- タブ
  - 消耗品
  - 素材
- アイテム名
- アイコン
- 説明
- 所持数

消耗品で表示する情報:

- 使用可否
- 使用対象
- 使用確認
- 消耗品所持上限
- 効果
  - HP回復
  - SP回復
  - 毒回復
  - 状態異常回復
  - 逃走成功
- 使用可能場面
  - 戦闘中
  - 探索中/キャンプ

素材で表示する情報:

- 素材カテゴリ
- 素材ランク
- 主な用途
- 所持数

素材は確認用に表示する。
素材はアイテム画面から使用しない。

表示しない情報:

- 素材の全レシピ逆引き
- 入手場所の詳細
- 売却価格
- 内部効果ID

### 装備画面

- キャラクターごとの装備を変更する。
- 武器、防具、アクセサリーを扱う。
- 装備中に使用可能になるスキルも確認できる。

表示する情報:

- キャラクター一覧
- 選択中キャラクター
- 装備スロット
  - 武器
  - 防具
  - アクセサリー1
  - アクセサリー2
- 所持装備一覧
- 装備名
- アイコン
- レアリティ
- 基本性能
- ランダム補正
- 固定スキル
- ランダムスキル
- 装備可否
- 装備変更後のステータス差分
- 他キャラクターが装備中かどうか

表示しない情報:

- 装備の入手元
- レアリティ抽選確率
- 未所持装備
- 他キャラクターの詳細ステータス
- 内部個体ID
- 売却不可/重要装備表示

他キャラクターが装備中の装備も付け替え可能とする。
その場合は「誰が装備中か」を表示し、確認後に付け替える。

### ステータス画面

- キャラクターの現在ステータスを表示する。
- 装備補正込みの最終値を表示する。
- 属性耐性、状態異常耐性、弱体耐性も確認できる。

表示する情報:

- キャラクター一覧
- 選択中キャラクター
- 名前
- Lv
- 経験値
- HP/SP
- 攻撃
- 魔力
- 防御
- 素早さ
- 会心率
- 前衛/後衛
- 装備中の武器、防具、アクセサリー
- 使用可能スキル
  - 固有スキル
  - 装備スキル
- スキル名
- スキル説明
- 消費SP
- 対象
- 属性耐性
- 状態異常耐性
- 弱体耐性

表示しない情報:

- 未加入キャラクター
- エピローグ条件
- 内部ID
- 詳細な経験値計算式
- 隠しフラグ

### 隊列画面

- 各キャラクターの前衛/後衛を設定する。
- 戦闘参加メンバーの隊列を確認・変更する。
- 戦闘参加メンバーのみを表示する。
- 控えメンバーは表示しない。
- 前衛は最低1人必要とする。
- 4人全員前衛は可能。
- 4人全員後衛は不可。

表示する情報:

- 戦闘参加メンバー
- 前衛枠
- 後衛枠

表示しない情報:

- 控えメンバー
- 未加入キャラクター
- 役割メモ
- HP/SP
- 装備中の武器
- 詳細ステータス
- スキル詳細
- 敵から狙われる内部確率
- 隊列補正の詳細計算式

## クエスト・イベント系画面

### クエスト探索画面

- ノードマップを表示する。
- 現在ノード、接続先ノード、処理済み状態を表示する。
- ノード選択により、イベント、戦闘、宝箱、終了へ進む。
- 探索中はキャンプ画面を開ける。

表示する情報:

- ノードマップ
- 現在ノード
- 移動可能な接続先
- ノード種別アイコン
  - イベント
  - 戦闘
  - 宝箱
  - 終了
- 処理済みノード
- キャンプボタン
- 戻れない/進むのみなどの移動制限

表示しない情報:

- クエスト名
- 未到達ノードの詳細内容
- 敵編成の詳細
- 宝箱の中身
- 分岐条件の内部フラグ名
- クリア後イベントの内容

ノード種別はアイコンで表示する。
ただし、敵編成や宝箱の中身などの詳細は、該当ノードを処理するまで表示しない。

### イベント画面

- イベント本文、選択肢、結果を表示する。
- イベント効果に応じてフラグ、報酬、加入、戦闘開始などを処理する。
- イベント中は手動セーブ不可。

表示する情報:

- 背景
- 話者名
- 本文
- 吹き出し
- キャラクター立ち絵
- 選択肢
- 入手/消費/加入などの結果表示
- 次へボタン
- 設定ボタン

操作:

- クリックで文章送り。
- 選択肢クリックで決定する。
- イベント中に設定画面を開ける。
- イベント中のセーブ/ロードは不可。
- イベントスキップは初期要件では扱わない。

表示しない情報:

- イベントID
- フラグ名
- 発生条件
- 好感度や内部値
- 未選択肢の結果
- イベント既読状態

立ち絵がないキャラクターは、立ち絵なし表示を許容する。

### 戦闘画面

- ターン制コマンドバトルを行う。
- 攻撃、スキル、アイテム、防御、逃げるを選択する。
- 戦闘中は手動セーブ不可。

表示する情報:

- 味方一覧
  - 名前
  - HP
  - SP
  - 状態異常/状態変化
- 敵一覧
  - 敵グラフィック
  - 敵名
  - HPゲージ
  - 状態異常/状態変化
- 行動順
- コマンド
  - 攻撃
  - スキル
  - アイテム
  - 防御
  - 逃げる
- 選択中コマンドの説明
- スキル一覧
  - 消費SP
  - 対象
  - 簡単な効果
- アイテム一覧
  - 所持数
  - 簡単な効果
- 戦闘ログ

表示しない情報:

- 敵HPの数値
- 敵の正確なステータス
- 敵の行動テーブル
- 敵のドロップ率
- ダメージ計算式
- 内部成功率

敵HPは数値ではなくゲージのみで表示する。

### 報酬・結果表示方針

- 報酬表示専用画面は初期要件では作らない。
- クエスト/うろつき終了用のリザルト画面は初期要件では作らない。
- 戦闘勝利、宝箱、イベント報酬で得た内容は、イベント本文または短い通知で表示する。
- クエスト終了結果や報酬は、必要に応じて終了イベント内で表示する。
- 終了処理後は、日付進行とオートセーブを行いホームへ戻る。

表示しない情報:

- 獲得報酬の合計リザルト
- 敵ごとのドロップ率
- 報酬判定の内訳
- 未取得報酬
- 内部フラグ

## エンディング系画面

### エンディング画面

- 本筋エンディングを表示する。
- 未達、通常、良、真、敗北などの結果を扱う。

### エピローグ画面

- 条件を満たした追加エピローグを表示する。
- 複数条件を満たした場合は複数表示してよい。

### 周回結果画面

- 周回で到達したエンディング、表示されたエピローグ、簡単な結果を表示する。
- 永続セーブデータへ記録する。
- 表示後、タイトルまたは新規周回開始へ遷移する。

## 戻る操作

- 各サブ画面は、基本的に開いた元の画面へ戻る。
- ホームから開いた画面はホームへ戻る。
- 探索中にキャンプを開いた場合は、探索画面へ戻る。
- イベント中、戦闘中は任意の戻る操作で中断しない。

## セーブ不可画面

以下の画面では手動セーブ不可とする。

- クエスト探索画面
- イベント画面
- 戦闘画面
- エンディング画面
- エピローグ画面
- 周回結果画面
