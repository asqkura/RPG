# イベント管理

イベントは、物語・キャラクター進行・フラグ更新を持つ一回性の出来事として扱う。
何度でも発生する素材入手やランダム戦闘などは、イベントではなく汎用結果として扱う。

## イベント分類

- メインイベント
  - 日数やメイン進行度で発生する本筋イベント。

- うろつきイベント
  - 場所を選んだときに発生するイベント。

- キャラクターイベント
  - 仲間ごとの段階制イベント。

- クエストイベント
  - クエスト開始時・途中・終了時に発生するイベント。

- 戦闘イベント
  - 戦闘前後、特定ターン、勝利/敗北時に発生するイベント。

- システムイベント
  - チュートリアル、解放通知など。

## EventData

- `eventId`
  - 一意ID。

- `eventType`
  - メイン / うろつき / キャラクター / クエスト / 戦闘 / システム。

- `title`
  - 表示名、管理名。

- `conditions`
  - 発生条件。

- `priorityCategory`
  - 強制 / 重要 / 通常 / 汎用。

- `weight`
  - 通常抽選に使う重み。

- `steps`
  - イベント表示や選択肢の流れ。
  - 会話、地の文、選択肢、効果実行などを順番に並べる。

- `effects`
  - イベント完了時に実行するゲーム状態変更。
  - 選択肢や途中効果は `steps` 側にも持てる。

- `nextEventId`
  - 連続イベントの参照用。実際の進行はフラグや段階で管理する。

- `backgroundSprite`
  - イベント開始時の背景Sprite参照。
  - ステップ側で変更してもよい。

- `bgmId`
  - イベント開始時のBGM ID。
  - ステップ側で変更してもよい。

## EventStep

イベント中の1ステップを表す。
会話、地の文、選択肢、演出、効果実行を順番に処理する。

```text
stepType
speakerName
text
characterSprite
backgroundSprite
bgmId
soundEffectId
choices
effects
```

### 項目

- `stepType`
  - `message`
  - `narration`
  - `choice`
  - `effect`
  - `changeBackground`
  - `changeBgm`
  - `soundEffect`

- `speakerName`
  - 話者名。
  - 地の文では空にしてよい。

- `text`
  - 表示する本文。

- `characterSprite`
  - 表示するキャラクター立ち絵Sprite参照。
  - 立ち絵がない場合は空にしてよい。

- `backgroundSprite`
  - 背景変更に使うSprite参照。

- `bgmId`
  - BGM変更に使うID。

- `soundEffectId`
  - 再生するSE ID。

- `choices`
  - 選択肢一覧。
  - `stepType = choice` の場合に使う。

- `effects`
  - このステップで即時実行する効果。

## EventChoice

```text
choiceId
label
conditions
effects
nextStepIndex
```

### 項目

- `choiceId`
  - 選択肢ID。

- `label`
  - 選択肢表示テキスト。

- `conditions`
  - 選択肢の表示・選択条件。

- `effects`
  - 選択時に実行する効果。

- `nextStepIndex`
  - 選択後に進むステップ。
  - 空の場合は次のステップへ進む。

## EventEffect

イベント効果は、実際のゲーム状態変更に絞る。

```text
effectType
targetId
value
amount
conditions
```

### 項目

- `effectType`
  - 効果種別。

- `targetId`
  - 対象ID。
  - アイテムID、装備ID、キャラクターID、クエストID、フラグID、戦闘IDなど。

- `value`
  - 設定値。
  - フラグ値、進行段階、解放状態など。

- `amount`
  - 増減量。
  - お金、アイテム数、素材数、経験値など。

- `conditions`
  - 効果実行条件。

### 効果種別

- フラグを立てる/消す。
- 数値を増減する。
- キャラクターを加入/離脱させる。
- クエストを解放する。
- うろつき場所を解放する。
- アイテム/素材/お金を付与する。
- アイテム/素材/お金を消費する。
- 装備を付与する。
- 戦闘を開始する。
- 合成レベルを変更する。
- レシピを解放する。
- エピローグ候補を解放する。

## EventDataに持たせないもの

- `speakerName`
  - 話者名は `EventStep` 側に持たせる。

- `characterSprite`
  - 立ち絵は `EventStep` 側に持たせる。

- `choices`
  - 選択肢は `EventStep` 側に持たせる。

- `autoStartBattleId`
  - 戦闘開始は `EventEffect` で扱う。

- 通常イベント閲覧記録
  - 永続保存しない。

## 発生条件

イベント条件には以下を使える。

- 日数
- フェーズ
- メイン進行度
- 場所
- クエストID
- キャラクター加入状態
- キャラクター編成状態
- キャラクターイベント段階
- フラグ
- アイテム所持
- 装備所持
- 合成レベル
- 戦闘勝敗
- 周回内の発生済み/未発生
- ランダム確率

アイテム所持・装備所持は使えるようにするが、メイン進行やエンディング分岐の主条件には基本しない。
主な用途は合成・工房イベント、サブイベント、任意報酬イベント、NPCへの納品などにする。

## 優先カテゴリ

- 強制
  - 条件を満たしたら必ず発生する。
  - メイン進行、チュートリアル、重要な割り込みイベントに使う。
  - 条件を満たした強制イベントが複数ある場合、1日に発生するのは1つだけ。
  - 発生しなかった強制イベントは、条件を満たしている限り次回以降の候補に残る。

- 重要
  - 優先的に発生する。
  - キャラクター段階イベント、仲間加入イベント、ルート関連イベントに使う。
  - 複数ある場合は、優先順位または重みで選ぶ。

- 通常
  - 通常の重み抽選対象。
  - 会話、素材入手、戦闘、小イベントなどに使う。

- 汎用
  - 何も発生しない時のフォールバック。
  - 噂、雑談、何も起きない結果などに使う。

解放通知、報酬表示のような軽いシステム通知は、強制イベントの1日1件制限とは別に連続表示してよい。

## 再発生ルール

- イベントは原則として周回中1回のみ発生する。
- 同じ `eventId` は、同じ周回では再発生しない。
- 周回内の重複防止には `occurredEventIds` を使う。
- `occurredEventIds` は周回終了でリセットする。
- 通常イベント閲覧記録は永続保存しない。

## 汎用結果

何度でも発生するものはイベントではなく汎用結果として扱う。

- 素材を拾った。
- 魔物に遭遇した。
- 噂を聞いた。
- 何も起きなかった。
- 小銭を拾った。

## WanderLocationData

うろつき場所を表すデータ。
うろつき選択画面では、場所名と短い説明のみを表示する。

```text
locationId
name
description
unlockConditions
eventCandidateIds
fallbackEventId
sortOrder
```

### 項目

- `locationId`
  - 一意ID。

- `name`
  - 場所名。

- `description`
  - 場所の短い説明。

- `unlockConditions`
  - 場所の解放条件。

- `eventCandidateIds`
  - その場所で発生候補になるイベントID一覧。

- `fallbackEventId`
  - 発生条件を満たすイベントがない場合に使うイベントID。
  - 何も起きない、雑談、軽い汎用結果などに使う。

- `sortOrder`
  - うろつき場所一覧での表示順。

### WanderLocationDataに持たせないもの

- `backgroundSprite`
  - 背景はイベント側に持たせる。

- `bgmId`
  - BGMはイベント側に持たせる。

## 連続イベント

- 連続イベントは、同じイベントを再発生させず、複数のイベントIDで構成する。
- 各イベントは周回中1回のみ発生する。
- イベント発生後、段階フラグや状態フラグを更新する。
- 次段階イベントは、そのフラグを発生条件として参照する。
- 分岐イベントは、選択肢や結果フラグを条件にして別イベントIDへ分岐する。

例:

- `char_a_001`
  - 条件: `charAStage = 0`
  - 効果: `charAStage = 1`

- `char_a_002`
  - 条件: `charAStage = 1`, `day >= 11`
  - 効果: `charAStage = 2`

- `char_a_003`
  - 条件: `charAStage = 2`, `特定クエストクリア済み`
  - 効果: `charAStage = 3`, `charAEpilogueUnlocked = true`

## イベント効果方針

イベント効果として、図鑑登録や通常イベント閲覧記録の登録は扱わない。
エンディング・エピローグ記録は、それらを表示したタイミングで自動登録する。
